# 🚀 Streakify

Streakify is a full-stack gamified learning platform that transforms technical practice into an engaging daily habit. Users can solve subject-based quizzes, maintain learning streaks, earn XP, unlock achievements, and climb a real-time leaderboard—all while tracking their progress through an intuitive dashboard.

## ✨ Features

- 🔐 User Authentication (Register/Login)
- 🎯 Daily quiz system
- 📚 Topic-wise learning
  - SQL
  - NoSQL
  - JavaScript
  - Java
  - DCN
- ❤️ Heart system
- ⚡ XP reward system
- 🔥 Daily streak tracking
- 🏆 Leaderboard
- 🛒 Shop to refill hearts using XP
- 📱 Fully responsive design
- 🎨 Gamified UI inspired by Duolingo
- ☁️ Cloud database using MongoDB Atlas
- 🚀 Deployed using Vercel
- 📱 Responsive UI that adapts seamlessly across mobile, tablet, and desktop devices.

---

## 🎮 How It Works

1. Register a new account.
2. Login securely.
3. Choose a topic.
4. Answer five daily questions.
5. Earn XP for correct answers.
6. Lose hearts for wrong answers.
7. Complete the lesson to maintain your streak.
8. Spend XP in the Shop to refill hearts.
9. Compete with other users on the leaderboard.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Pavithra-67/streakify.git
```

---

### Move into the project

```bash
cd streakify
```

---

### Install dependencies

```bash
npm install
```

---

### Create a `.env.local`

```env
MONGODB_URI=Your_MongoDB_Connection_String
MONGODB_DB=streakify
JWT_SECRET=Your_JWT_Secret
```

---

### Run locally

```bash
npm run dev
```

Open

```
http://localhost:3000
```
